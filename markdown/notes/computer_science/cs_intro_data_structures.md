# Introduction to Data Structures

_Last Updated: 2025-03-28_

## What is a Data Structure?

A data structure is a systematic way to organize and manage data efficiently. It facilitates easy storage, retrieval, and manipulation.

## Types of Data Structures:
- **Primitive** (int, float, char, boolean)
- **Non-Primitive**:
  - Linear: Arrays, Linked Lists, Stacks, Queues
  - Non-Linear: Trees, Graphs

## Applications:
- Databases
- Operating Systems
- Compiler Design
- Artificial Intelligence
