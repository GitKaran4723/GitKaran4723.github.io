ML - Unit 2 Overview

Types of Machine Learning:

  • Supervised Learning: The algorithm is trained on labeled data.
  • Unsupervised Learning: The algorithm learns patterns without labeled outputs.
  • Reinforcement Learning: Learning through interaction with an environment and feedback.

Applications of Machine Learning:

  • Image and Speech Recognition: Recognizing and interpreting images and speech.
  • Healthcare: Applied for disease prediction, drug discovery, and personalized medicine.
  • Finance: Used for fraud detection, credit scoring, and stock market analysis.
  • Natural Language Processing (NLP): Enabling machines to understand and generate human-like text.

Preparing to Model:

  • Data Collection: Gathering relevant and sufficient data for the task.
  • Data Cleaning: Removing errors, handling missing values, and ensuring data is usable.
  • Data Exploration: Understanding data patterns through statistical and visual analysis.

Basic Types of Data in Machine Learning:

  • Numerical Data: Represented by numbers, can be discrete or continuous.
  • Categorical Data: Falls into categories without a meaningful numerical value.
  • Ordinal Data: Categorical data with a meaningful order or ranking.

Exploring Structures of Data:

  • Descriptive Statistics: Summarizing main features using mean, median, etc.
  • Data Visualization: Representing data graphically through charts and plots.

Data Quality and Remediation:

  • Data Quality Assessment: Evaluating reliability, accuracy, and completeness of the dataset.
  • Data Cleaning and Imputation: Addressing issues like missing values, outliers, and errors.
  • Feature Engineering: Creating or transforming features to enhance model performance.
